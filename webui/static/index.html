House rules

State of the bench

Every number here was measured, or it isn't here.

Gantry runs contributed data through a fixed gauntlet — read, convert, train, evaluate closed-loop, compare against a shuffled control — and reports what survived. Rates carry their intervals, refusals carry their codes, and “could not tell you” is an answer.

02 · Datasets

What went in, and what it declared.

A dataset is read as it describes itself or not at all. Uploads run through the same checks the pipeline uses — schema, stats, sidecar, licence, and the two-handedness measure the contributor split is built on.

The contributor split

Two cohorts cut from the same footage on one measured property — the fraction of frames in which both hands were actually moving. An arm the tracker lost is held at its last value: a frozen block, invisible to every schema check.

03 · Runs

Closed-loop, on screened scenes, with the ladder.

Each run is a policy facing arrangements RoboTwin's own expert first proved solvable. The binary outcome is kept — but the ladder underneath it is where the signal is when success sits near the floor.

04 · Compare

Only the disagreements carry information.

Two arms on the same scenes agree about most of them — the easy ones both manage, the hard ones both fail. This pairs them scene by scene and runs McNemar's exact test on the scenes where they differ.
